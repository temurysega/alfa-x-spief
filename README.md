# Квиз ALFA INSIDE 

Викторина с ведущим в прямом эфире: школьники отвечают с телефона по ссылке, ведущий управляет игрой из пульта на `/admin`. Две игры (10.11 и 12.11), общий рейтинг, рассчитано на 300 участников одновременно.

## Запустить у себя

Нужен [Docker Desktop](https://www.docker.com/products/docker-desktop/).

```bash
cp .env.example .env        # и поменять пароли в .env
docker compose up -d --build
```

- игра: http://localhost:8080
- пульт ведущего: http://localhost:8080/admin, пароль — `ADMIN_PASSWORD` из `.env`
- с телефона в той же Wi-Fi: `http://<IP компьютера>:8080`

Несколько участников в одном браузере: добавь к адресу `?slot=2`, `?slot=3` — у каждого слота свой вход. Без этого вкладки делят один вход.

Остановить: `docker compose down`. Данные (база, картинки) лежат в томах `alfa-quiz_db` и `alfa-quiz_data` и переживают перезапуск. Стереть всё начисто: `docker compose down -v`.

## Как сыграть пробную игру

1. Пульт → «Вопросы» → «Загрузить файл» → `questions/example-game1.json`.
2. Открыть игру в другой вкладке или на телефоне, войти с ником.
3. Пульт → «Пульт» → «Запустить вопрос 1». Через 5 секунд отсчёта у участника откроются варианты, через 30 секунд — правильный ответ.
4. После прогона: «Сервис» → «Сброс».

## Вопросы

Загружаются в пульте файлом JSON или CSV, вместе с ним можно выбрать картинки — файл ссылается на них по имени. Загрузка заменяет все вопросы выбранной игры. Картинки сжимаются в браузере до ~150 КБ.

**JSON** — см. [questions/example-game1.json](questions/example-game1.json):

```json
{ "questions": [
  { "text": "Что из этого — генеративный ИИ?", "image": "q1.png",
    "options": ["…", "…", "…", "…", "…"], "correct": 3, "seconds": 30, "double": false }
] }
```

**CSV** — см. [questions/example.csv](questions/example.csv). Колонки: `вопрос; картинка; вариант 1 … вариант 5; правильный; секунды; двойные`. Excel сохраняет и в UTF-8, и в windows-1251 — подходят оба.

`correct` / `правильный` — номер правильного варианта с 1 или буква А–Д. Вариантов от 2 до 5. `double` / `двойные` — двойные баллы (в CSV — «да»).

## Разработка

```bash
cd server && npm install && npm test          # тесты подсчёта рейтинга и фильтра ников
cd server && npm run typecheck
cd client && npm install && npm run dev       # интерфейс с горячей перезагрузкой: http://localhost:5173
```

`npm run dev` ходит за данными в запущенный `docker compose`. После правок сервера: `docker compose up -d --build server`.

Нагрузочный тест — 300 ботов входят и отвечают в первые 2 секунды каждого вопроса, в конце сверяется рейтинг:

```bash
cd server && node tools/bots.ts --password <ADMIN_PASSWORD> --bots 300 --reset
```

`--reset` стирает участников и ответы и загружает примерные вопросы. Только для локального стенда и прогонов.

## Как устроено

```
телефон ──► nginx ──► /state/<токен>.json   готовые снимки с диска, раз в 2,5 с
                 ├──► /api/time             серверное время для синхронизации таймера
                 ├──► /api/join, /login, /answer, /admin/…  ──► server (Node + TypeScript) ──► PostgreSQL
                 └──► клиент и картинки
```

- Всё состояние — на сервере, в базе. На каждое изменение сервер пишет каждому участнику файл-снимок, клиент только показывает его. После перезапуска игра продолжается с того же места.
- Правильный ответ попадает в снимок только после закрытия вопроса. Баллов и места в снимке нет.
- Ответ принимается, только если он пришёл в окне «открытие вопроса … дедлайн + 1 с». Время сравнивает база, а не код. Второй ответ на тот же вопрос отсекается уникальным ключом.
- Подсчёт рейтинга — одна функция с тестами: [server/src/scoring.ts](server/src/scoring.ts).
- Фильтр ников: [server/src/nick.ts](server/src/nick.ts). Что-то он пропустит — в пульте есть «Переименовать» и «Удалить».
- Журнал входов и ответов только дописывается (запрет на правку и удаление стоит в самой базе) — по нему разбираем споры о победителях.
- Оформление — выжимка из дизайн-системы Софьи: [client/src/styles/alfa-inside.css](client/src/styles/alfa-inside.css). Шрифты лежат в проекте, а не в Google Fonts.

| Папка | Что внутри |
|---|---|
| `server/src` | вход, ответы, команды ведущего, тикер закрытия вопросов, сборка снимков |
| `server/tools/bots.ts` | нагрузочный тест |
| `client/src/player` | экраны участника |
| `client/src/admin` | пульт ведущего |
| `nginx` | конфиг и сборка образа с клиентом |
| `questions` | примеры файлов вопросов |

## На сервер (позже)

На VPS с Docker:

```bash
git clone https://github.com/temurysega/alfa-x-spief.git && cd alfa-x-spief
cp .env.example .env   # длинные случайные пароли
docker compose up -d --build
```

Обновление — `git pull && docker compose up -d --build`. HTTPS и домен настроим при переезде на сервер.

Важно:
- версии образов закреплены, `latest` не используем;
- `.env` с паролями не попадает в git;
- имя проекта `alfa-quiz` в `docker-compose.yml` не менять — иначе стек поднимется на пустой базе.
